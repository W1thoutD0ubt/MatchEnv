# CreateVase

```lua
CreateVase(row, column, options)
```

在指定位置创建罐子，返回 `PVZ::Vase`。行、列从 0 开始编号；`options` 必须是 table，不能省略或传入 `nil`。

## 配置字段

| 字段 | 类型及取值 | 说明 |
|------|------------|------|
| `Plant` | 整数 | 内含的植物卡片类型编号 |
| `Zombie` | 整数 | 内含的僵尸类型编号 |
| `Sun` | 整数 | 内含的阳光总量 |
| `Skin` | `"normal"`、`"leaf"`、`"zombie"` | 普通罐、绿罐、僵尸罐，默认 `"normal"` |

`Plant`、`Zombie`、`Sun` 最多只能指定一个，全部不指定时生成空罐。编号 0 是有效内容，`Sun = 0` 也算指定了内容。字段值为 `nil` 等同于未指定。

外观与内容物独立设置，例如绿罐可以装僵尸，不会根据内容物自动改变外观。

植物、僵尸编号和阳光数量不作业务取值范围限制，负数也会原样传给底层；数值须能以底层的 32 位有符号整数表示。

所有配置在创建前校验。内容字段冲突、未知字段、非字符串键、错误类型、小数、非有限数值、超出 32 位有符号整数范围的数值和无效外观都会触发 Lua 错误，不创建罐子。字段名和外观字符串区分大小写。

## 示例

在初始化回调中调用：

```lua
CreateVase(0, 4, { Zombie = 0 })                  -- 普通罐，内含普通僵尸
CreateVase(1, 4, { Plant = 0, Skin = "leaf" })     -- 绿罐，内含豌豆射手卡片
CreateVase(2, 4, { Zombie = 4, Skin = "zombie" })  -- 僵尸罐，内含铁桶僵尸
CreateVase(3, 4, { Sun = 100 })                   -- 普通罐，内含 100 阳光
CreateVase(4, 4, {})                              -- 空罐
CreateVase(0, 5, { Zombie = 0, Skin = "leaf" })    -- 绿罐，内含普通僵尸
```
